    multiScan200 REST API | OpenAPI V1.1.0¶

    This page provides the searchable V1.1.0 REST reference and downloadable OpenAPI description for the multiScan200 family. For REST concepts, authentication, and request patterns, see REST API / OpenAPI.

    OpenAPI File¶

    • multiScan200 V1.1.0 - OpenAPI (YAML)

    Always match the file to your device's actual firmware version. Function availability can vary by variant and installed software package.
