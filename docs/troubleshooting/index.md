# Troubleshooting

Compatible with: LRS4000 multiScan100 multiScan200 picoScan100

Start here when a sensor does not connect, does not send data, or reports an error.

* [Common Issues](https://sickag.github.io/sick_lidar_developer_guide/troubleshooting/common-issues/): symptom and check tables for connection, configuration, and measurement data.
* [Diagnostics](https://sickag.github.io/sick_lidar_developer_guide/troubleshooting/diagnostics/): create a diagnostic file on the device and send it to SICK for analysis.
* [Error Codes](https://sickag.github.io/sick_lidar_developer_guide/troubleshooting/error-codes/): interpret reported errors and recommended actions.

## Get Support

Create a diagnostic file in SOPASair (**Diagnostics → Overview → Diagnostic file**) and send it to SICK with a description of the problem. See [Diagnostics](https://sickag.github.io/sick_lidar_developer_guide/troubleshooting/diagnostics/) and [Contact](https://sickag.github.io/sick_lidar_developer_guide/contact/).
