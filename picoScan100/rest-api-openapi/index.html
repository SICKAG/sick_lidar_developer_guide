    REST API | OpenAPI¶

    Compatible with: picoScan100

    This page provides the downloadable OpenAPI descriptions and interactive endpoint reference for picoScan devices. For general REST API concepts, authentication, and request patterns, see REST API / OpenAPI.

    OpenAPI Files¶

    Sample OpenAPI descriptions for the Service interface, shipped with this guide for reference:

    • picoScan150 v2.3.3.0R - Service OpenAPI (YAML)
    • picoScan120 v2.3.3.0R - Service OpenAPI (YAML)

    Always match the file to your device's actual firmware version; endpoints, parameters, and schemas change between releases.

    Interactive Endpoint Reference¶

    The full endpoint reference below is rendered directly from the OpenAPI files above. Expand an endpoint to see its parameters, request body, and response schema, or use Try it out against a reachable device (writes still require challenge-response authentication).

    For the general REST API explanation and authentication details, return to REST API / OpenAPI.
