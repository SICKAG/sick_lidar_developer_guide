    Cable Dimensioning¶

    Compatible with: LRS4000 multiScan100 multiScan200 picoScan100

    Select a device to prefill its power consumption, minimum sensor voltage, and number of supply wires. Choose a load condition to check typical, maximum, or startup consumption where specified in the operating instructions. Custom Values lets you adjust the device-specific inputs, for example to add digital output loads or combine sensors. Supply voltage and cable specifications remain editable for every device. Select the question-mark icon beside an input for guidance.

    Input

    ?

    Typical or maximum power consumption from the technical data in the operating instructions. Include digital output loads and add all sensors sharing the cable.

    ?

    Lower limit of the supply voltage range in the technical data of the operating instructions.

    ?

    Output voltage of the power supply under load, minus its tolerance. Typically 24 V.

    ?

    One-way length from the power supply to the sensor connector, including extension cables.

    ?

    Conductor cross-section from the cable data sheet, often given as AWG.

    ?

    Number of wires connected in parallel for supply and for ground. See the pin assignment of the sensor connector.

    ?

    Highest expected temperature of the cable in operation. Warmer copper has a higher resistance.

    General remarks:

    • Measure the voltage at the sensor connector under load to verify the installation.
    • Check the startup load as well as normal operation: the starting current can cause a voltage drop that prevents the sensor from starting.
    • Take the supply voltage range and power consumption of your variant from its operating instructions on sick.com, and include digital output loads in the entered power.
    • To reduce voltage drop, shorten the cable, increase its cross-section, use two parallel wires per path (halves the resistance), or use a higher permitted supply voltage.
    • This estimate does not check cable ampacity, connector ratings, fusing, or electrical safety.

    Device-specific remarks:

    • Device presets default to maximum operating consumption, not startup consumption. Select the startup load where available, or use Custom Values with the startup data from the operating instructions.
    • LRS4000 presets exclude digital output loads; select Custom Values to add them.
    • The multiScan100 presets cover multiScan136, multiScan165, and multiScan166; multiScan200 uses multiScan270 data; picoScan100 uses picoScan150 data. Verify the operating instructions for your exact variant.
    • multiScan270 requires both supply and ground pin pairs: see Electrical Connection.
