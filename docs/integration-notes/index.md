# Integration Notes

Connect sensor data and configuration to your application using the tools
and interfaces that fit your system.

* [3D With 2D LiDARs](https://sickag.github.io/sick_lidar_developer_guide/integration-notes/3d-with-2d-lidars/): combine planar scans and motion information into point clouds.
* [Cable Dimensioning](https://sickag.github.io/sick_lidar_developer_guide/integration-notes/cable-dimensioning/): estimate supply-cable voltage drop.
* [Coding Tools & Examples](https://sickag.github.io/sick_lidar_developer_guide/integration-notes/coding-tools-and-examples/): find SDKs, clients, scan receivers, and parser definitions.
* [Cybersecurity](https://sickag.github.io/sick_lidar_developer_guide/integration-notes/cybersecurity/): review network access, passwords, HTTPS, and data integrity.
* [Kaitai Struct Parsers](https://sickag.github.io/sick_lidar_developer_guide/integration-notes/kaitai-struct-parsers/): generate Compact parsers from format definitions.
* [MATLAB Integration](https://sickag.github.io/sick_lidar_developer_guide/integration-notes/matlab-integration/): receive native ROS 2 point clouds with ROS Toolbox.
* [Milestones Camera Plugin](https://sickag.github.io/sick_lidar_developer_guide/integration-notes/milestones-camera/): integrate cameras with Milestone XProtect and align timing.
* [Model Context](https://sickag.github.io/sick_lidar_developer_guide/integration-notes/model-context/): give coding assistants context from local documentation repositories.
* [PLC Integration](https://sickag.github.io/sick_lidar_developer_guide/integration-notes/plc-integration/): exchange CoLa B telegrams with PLCs over TCP.
* [ROS Integration](https://sickag.github.io/sick_lidar_developer_guide/integration-notes/ros-integration/): choose native ROS 2 or the host-side driver.
