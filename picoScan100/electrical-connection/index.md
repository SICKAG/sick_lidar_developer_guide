# Electrical Connection

## PWR / 3 IOs

System plug part number: 2116047

This system plug uses a male, 5-pin, A-coded M12 connector.

![5-pin PWR connector face with numbered pins](../assets/electrical-symbols/picoscan100-pwr-5.png)
<p class="caption connector-caption">5-pin PWR connector face with numbered pins.</p>

<p class="table-caption" markdown>**PWR / 3 IOs** connector pin assignments and signal functions.</p>

| Pin | Signal | Function |
| --- | --- | --- |
| 1 | `Vs` | Supply, +9 V DC to +30 V DC |
| 2 | `IN2/OUT2` | Configurable digital input 2 or output 2 |
| 3 | `GND` | Supply return, 0 V |
| 4 | `IN1/OUT1` | Configurable digital input 1 or output 1 |
| 5 | `IN3/OUT3` | Configurable digital input 3 or output 3 |

## PoE

System plug part number: 2149035

This system plug uses a female, 5-pin, A-coded M12 connector.

![PoE connector face with numbered pins](../assets/electrical-symbols/picoscan100-poe.png)
<p class="caption connector-caption">PoE connector face with numbered pins.</p>

<p class="table-caption" markdown>**PoE** connector pin assignments and signal functions.</p>

| Pin | Signal | Function |
| --- | --- | --- |
| 1 | `In1` | Digital input 1 |
| 2 | `A` | Volt-free switching contact A |
| 3 | `GND` | Supply return, 0 V |
| 4 | `B` | Volt-free switching contact B |
| 5 | — | Reserved; do not connect |

## Ethernet

The Ethernet connection uses a female, 4-pin, D-coded M12 connector.

![Ethernet connector face with numbered pins](../assets/electrical-symbols/picoscan100-ethernet.png)
<p class="caption connector-caption">Ethernet connector face with numbered pins.</p>

<p class="table-caption" markdown>**Ethernet** connector pin assignments and signal functions.</p>

| Pin | Signal | Function |
| --- | --- | --- |
| 1 | `TX+` | Transmit + |
| 2 | `RX+` | Receive + |
| 3 | `TX-` | Transmit − |
| 4 | `RX-` | Receive − |
