# POST /SetObjectEvaluationContour

> multiScan100 API | REST | OpenAPI V2.5.0 › Object evaluation

Source: https://sickag.github.io/sick_lidar_developer_guide/multiScan100/api-rest-openapi/#rest-post-setobjectevaluationcontour

Sets the region of interest of an object detection evaluation.

This function requires at least user level: Authorized Client.
