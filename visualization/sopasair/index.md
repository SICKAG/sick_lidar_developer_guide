# SOPASair

SOPASair is the sensor's built-in web UI, served directly from the device at `http://192.168.0.1/` with factory settings. There is nothing to install: point a browser at the sensor. Use it to:

- configure the settings available on the selected device,
- draw or teach in field-evaluation zones where the device supports those functions,
- update firmware through the web UI where supported, or use the documented [REST sequence](../shared-features/firmware-update.md),
- create a diagnostic file if the device provides that option.

Screen-by-screen walkthroughs are available for the [LRS4000](../LRS4000/graphical-user-interface.md), [multiScan100](../multiScan100/graphical-user-interface.md), and [picoScan100](../picoScan100/graphical-user-interface.md). Available menus and functions vary by product family, variant, and firmware. For standard IP address settings, see [Getting Started](../getting-started.md).

For measurement recordings, see the [SOPASair Data recorder](../recording/sopasair.md) if that function is available on your device.
