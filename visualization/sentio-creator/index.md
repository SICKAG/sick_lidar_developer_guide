# Sentio Creator

Sentio Creator is a SICK software tool, published on [sick.com](https://www.sick.com/de/en/search?text=sentio-creator), used to configure and commission supported SICK devices. Alongside the device's product page, it is also a source for firmware update packages. Use it to obtain the correct package for your device variant before running a [firmware update](../shared-features/firmware-update.md).
