# SOPAS ET

Compatible with: LRS4000 multiScan100 multiScan200 picoScan100

SOPAS ET is a legacy SICK engineering tool. Use SOPASair for supported device setup and configuration workflows.

![SOPAS Engineering Tool user interface](https://sickag.github.io/sick_lidar_developer_guide/assets/visualization/sopas-et.png)
*SOPAS Engineering Tool interface with device search and project view.*

SOPAS ET can still be useful for discovering sensors on the local network. Use its network search to locate a device when its IP address is unknown, then continue commissioning in SOPASair or through the [REST API](https://sickag.github.io/sick_lidar_developer_guide/configuration/rest-interface/).

SOPAS ET also includes the **SOPAS ET Terminal** feature, which can send
[CoLa A and CoLa B commands](https://sickag.github.io/sick_lidar_developer_guide/configuration/cola-interface/) to sensors over TCP.
