# GET /ActualEncPosition2Enable

> picoScan150 API | REST | OpenAPI › Encoder Data Output

Source: https://sickag.github.io/sick_lidar_developer_guide/picoScan100/picoScan150/api-rest-openapi/#picoscan150-rest-get-actualencposition2enable

Enables/disables the use of the 2nd reference signal (port 4).

**Try the request**

Copy this command into a terminal. In Windows PowerShell, use `curl.exe` instead of `curl`.

```bash
curl --request GET "http://192.168.0.1/api/ActualEncPosition2Enable"
```
