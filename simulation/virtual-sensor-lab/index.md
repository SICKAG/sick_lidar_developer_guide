# Virtual Sensor Lab

The SICK Virtual Sensor Lab is a cloud service that gives you a live, virtual
SICK sensor in the browser. No hardware is required. It is the fastest way to
explore a device's web UI before the physical sensor is on your desk.

Open it at [devices.cloud.sick.com](https://devices.cloud.sick.com/).
