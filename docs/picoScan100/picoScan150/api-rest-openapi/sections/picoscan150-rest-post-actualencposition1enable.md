# POST /ActualEncPosition1Enable

> picoScan150 API | REST | OpenAPI › Encoder Data Output

Source: https://sickag.github.io/sick_lidar_developer_guide/picoScan100/picoScan150/api-rest-openapi/#picoscan150-rest-post-actualencposition1enable

This function requires at least user level: Authorized Client.
