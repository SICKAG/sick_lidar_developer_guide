# Virtual Sensor Lab

Compatible with: LRS4000 multiScan100 multiScan200 picoScan100

The cloud-based SICK Virtual Sensor Lab runs a live virtual sensor in your browser, so you can explore its web UI without hardware.

Open it at [devices.cloud.sick.com](https://devices.cloud.sick.com/).

- Explore every menu of the web UI and change settings, for example the data output or field-evaluation zones.
- Prepare a configuration offline, export it, and import it into a real device later. Configuration files from real devices can also be loaded and viewed.
- It does not replace commissioning or a function test on the real device. `.sopas` files cannot be imported or exported.
