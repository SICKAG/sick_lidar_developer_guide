    multiScan100 REST API | OpenAPI V2.5.0¶

    This page provides the searchable V2.5.0 REST reference and downloadable OpenAPI description for the multiScan100 family. For REST concepts, authentication, and request patterns, see REST API / OpenAPI.

    OpenAPI File¶

    • multiScan100 V2.5.0 - OpenAPI (YAML)

    Always match the file to your device's actual firmware version. Function availability can vary by variant and installed software package.

    The ScanDataFormat endpoint lists the value 4 (NativeROS2). The multiScan100 does not support native ROS 2. To use the multiScan100 with ROS 2, run the sick_scan_xd driver on the host.
