# Device-Specific Guides

Choose your sensor family for wiring, web-interface walkthroughs, command
references, downloads, and firmware information.

* [LRS4000](https://sickag.github.io/sick_lidar_developer_guide/LRS4000/): long-range 2D LiDAR, including motor synchronization.
* [multiScan100](https://sickag.github.io/sick_lidar_developer_guide/multiScan100/): multi-layer 3D LiDAR, including multiScan136, multiScan165, and multiScan166.
* [multiScan200](https://sickag.github.io/sick_lidar_developer_guide/multiScan200/): 3D LiDAR, including multiScan270.
* [picoScan100](https://sickag.github.io/sick_lidar_developer_guide/picoScan100/): compact 2D LiDAR, including picoScan120 and picoScan150.
