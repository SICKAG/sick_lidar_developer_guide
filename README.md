# SICK LiDAR Developer Guide

Integrate SICK LRS4000, multiScan100, multiScan200, and picoScan100 LiDAR
sensors into your application. The guide shows:

* Getting started, network setup, and configuration over REST and CoLa
* Data streaming formats, recording, and visualization
* On-device applications such as field evaluation
* Integration notes, calculators, beginner projects, and troubleshooting

## [Open the LiDAR Developer Guide →](https://sickag.github.io/sick_lidar_developer_guide/)

## About This Repository

This repository hosts the published website. The `docs/` folder contains
