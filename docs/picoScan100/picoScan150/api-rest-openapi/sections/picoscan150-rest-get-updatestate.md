# GET /UpdateState

> picoScan150 API | REST | OpenAPI › General

Source: https://sickag.github.io/sick_lidar_developer_guide/picoScan100/picoScan150/api-rest-openapi/#picoscan150-rest-get-updatestate

Returns the state of the update process.

**Try the request**

Copy this command into a terminal. In Windows PowerShell, use `curl.exe` instead of `curl`.

```bash
curl --request GET "http://192.168.0.1/api/UpdateState"
```

**Responses**

**Status `200`**

**Media type: `application/json`**

 |

`UpdateState`

**Allowed values:**

```
[

  1,
```
