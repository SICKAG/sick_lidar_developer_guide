Source: https://sickag.github.io/sick_lidar_developer_guide/visualization/sentio-creator/

# Sentio Creator

Compatible with: multiScan100 multiScan200 picoScan100

Sentio Creator is a SICK software tool, published on [sick.com](https://www.sick.com/de/en/search?text=sentio-creator), used to configure and commission supported SICK devices. Alongside the device's product page, it is also a source for firmware update packages. Use it to obtain the correct package for your device variant before running a [firmware update](https://sickag.github.io/sick_lidar_developer_guide/shared-features/firmware-update/).
