# multiScan100 Licenses and Part Numbers

> multiScan100 software licenses and part numbers for streaming, 3D object detection and tracking, filters, multi-echo, IMU, PTP, and interlaced mode.

Source: https://sickag.github.io/sick_lidar_developer_guide/multiScan100/licenses/

# Licenses

The following licenses enable multiScan100 device functions. Check the licenses
included with your device variant before ordering. For activation, see
[LiDAR License Activation](https://sickag.github.io/sick_lidar_developer_guide/shared-features/license-activation/).
