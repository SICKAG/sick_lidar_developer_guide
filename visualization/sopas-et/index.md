# SOPAS ET

SOPAS ET is a legacy SICK engineering tool and is no longer maintained for picoScan100 commissioning or configuration. Use SOPASair for supported device setup and configuration workflows.

![SOPAS Engineering Tool user interface](../assets/visualization/sopas-et.png)
*SOPAS Engineering Tool interface with device search and project view.*

SOPAS ET can still be useful for discovering sensors on the local network. Use its network search to locate a device when its IP address is unknown, then continue commissioning in SOPASair or through the [REST API](../configuration/rest-interface.md).
