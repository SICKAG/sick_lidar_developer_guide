# View LiDAR Point Clouds (PCD) in CloudCompare

> Open and inspect .pcd point clouds from 3D scan recording or the sick_perception_sdk in the free CloudCompare viewer.

Source: https://sickag.github.io/sick_lidar_developer_guide/visualization/cloudcompare/

# CloudCompare

Compatible with: LRS4000 multiScan100 multiScan200 picoScan100

<div class="tool-intro" markdown>

![CloudCompare](https://sickag.github.io/sick_lidar_developer_guide/assets/visualization/cloudcompare-logo.svg)
CloudCompare is a free, open-source 3D point-cloud viewer and processing tool. You can use it to visualize `.pcd` files produced by 3D scan recording or by the [sick_perception_sdk](https://sickag.github.io/sick_lidar_developer_guide/recording/sick-perception-sdk/), without writing any viewer code yourself.
