# CloudCompare

CloudCompare is a free, open-source 3D point-cloud viewer and processing tool. You can use it to visualize `.pcd` files produced by 3D scan recording or by the [sick_perception_sdk](../recording/sick-perception-sdk.md), without writing any viewer code yourself.
