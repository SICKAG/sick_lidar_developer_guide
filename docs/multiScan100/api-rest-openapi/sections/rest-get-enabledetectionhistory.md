# GET /EnableDetectionHistory

> multiScan100 API | REST | OpenAPI V2.5.0 › Detection history

Source: https://sickag.github.io/sick_lidar_developer_guide/multiScan100/api-rest-openapi/#rest-get-enabledetectionhistory

Enables/disables detection history.

**Try the request**

Copy this command into a terminal. In Windows PowerShell, use `curl.exe` instead of `curl`.

```bash
curl --request GET "http://192.168.0.1/api/EnableDetectionHistory"
```
