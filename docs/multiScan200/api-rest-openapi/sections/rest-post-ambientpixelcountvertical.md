# POST /ambientPixelCountVertical

> multiScan200 API | REST | OpenAPI V1.1.0 › Basic Settings

Source: https://sickag.github.io/sick_lidar_developer_guide/multiScan200/api-rest-openapi/#rest-post-ambientpixelcountvertical

Returns/sets the vertical ambient pixel count.

This function requires at least user level: Authorized Client.
