# GET /enableCloningPlug

> picoScan150 API | REST | OpenAPI › Inputs and Outputs

Source: https://sickag.github.io/sick_lidar_developer_guide/picoScan100/picoScan150/api-rest-openapi/#picoscan150-rest-get-enablecloningplug

Enables/disables the cloning functionality of the system plug.

**Try the request**

Copy this command into a terminal. In Windows PowerShell, use `curl.exe` instead of `curl`.

```bash
curl --request GET "http://192.168.0.1/api/enableCloningPlug"
```
