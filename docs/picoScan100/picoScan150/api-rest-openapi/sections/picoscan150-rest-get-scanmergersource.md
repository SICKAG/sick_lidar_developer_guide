# GET /ScanMergerSource

> picoScan150 API | REST | OpenAPI › 3D scan recording

Source: https://sickag.github.io/sick_lidar_developer_guide/picoScan100/picoScan150/api-rest-openapi/#picoscan150-rest-get-scanmergersource

Returns/sets the data source for angle information used during scan merging (IMU or ENCODER).

**Try the request**

Copy this command into a terminal. In Windows PowerShell, use `curl.exe` instead of `curl`.

```bash
curl --request GET "http://192.168.0.1/api/ScanMergerSource"
```

**Responses**

**Status `200`**

**Media type: `application/json`**

`ScanMergerSource`
