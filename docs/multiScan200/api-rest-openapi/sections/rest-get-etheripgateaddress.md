# GET /EtherIPGateAddress

> multiScan200 API | REST | OpenAPI V1.1.0 › Ethernet

Source: https://sickag.github.io/sick_lidar_developer_guide/multiScan200/api-rest-openapi/#rest-get-etheripgateaddress

Returns/sets the default gateway address.

**Try the request**

Copy this command into a terminal. In Windows PowerShell, use `curl.exe` instead of `curl`.

```bash
curl --request GET "http://192.168.0.1/api/EtherIPGateAddress"
```
