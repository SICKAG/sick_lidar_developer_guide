# GET /EncoderDataEnable

> picoScan150 API | REST | OpenAPI › Encoder Data Output

Source: https://sickag.github.io/sick_lidar_developer_guide/picoScan100/picoScan150/api-rest-openapi/#picoscan150-rest-get-encoderdataenable

Enables/disables the encoder data streaming. The encoder data itself is sent via a UDP-based SICK-specific format.

**Try the request**

Copy this command into a terminal. In Windows PowerShell, use `curl.exe` instead of `curl`.

```bash
curl --request GET "http://192.168.0.1/api/EncoderDataEnable"
```
