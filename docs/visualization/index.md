# LiDAR Visualization: SOPASair, SOPAS ET, rviz2, and More

> Choose SICK LiDAR software for live sensor setup, device commissioning, ROS topic checks, or offline point-cloud viewing.

Source: https://sickag.github.io/sick_lidar_developer_guide/visualization/

# Choose a Visualization Tool

Choose a tool based on whether you need to configure a live sensor, manage
devices and firmware, locate a device, or inspect point-cloud files.

* [SOPASair](https://sickag.github.io/sick_lidar_developer_guide/visualization/sopasair/): configure and commission a connected sensor in its browser-based interface, including interactive workflows such as field teach-in and firmware update. Start here.
* [ROS 2 rviz](https://sickag.github.io/sick_lidar_developer_guide/visualization/rviz2/): view live ROS 2 topics and point clouds to check data flow, frame alignment, and scan coverage; requires a running ROS 2 setup.
* [CloudCompare](https://sickag.github.io/sick_lidar_developer_guide/visualization/cloudcompare/): inspect and process saved 3D point clouds, including compatible PCD files; for offline work, not live sensor configuration.
* [Sentio Creator](https://sickag.github.io/sick_lidar_developer_guide/visualization/sentio-creator/): discover and commission SICK devices and find matching firmware packages; requires installing the SICK software.
* [SOPAS ET](https://sickag.github.io/sick_lidar_developer_guide/visualization/sopas-et/): use the legacy engineering tool across all device families for network discovery and CoLa commands; use SOPASair for supported device setup.
