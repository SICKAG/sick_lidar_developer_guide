# REST API | OpenAPI

![OpenAPI](../assets/openapi-logo.png)

This page provides the downloadable OpenAPI descriptions and interactive
endpoint reference for picoScan devices. For general REST API concepts,
authentication, and request patterns, see
[REST API / OpenAPI](../configuration/rest-interface.md).

## OpenAPI Files

Sample OpenAPI descriptions:

- [picoScan150 v2.3.3.0R - OpenAPI (YAML)](../assets/picoScan100/openapi/picoScan150_picoScan_2.3.3.0R_OpenApi.yaml)

parameters, and schemas change between releases.
