# picoScan100 Licenses and Part Numbers

> picoScan100 software licenses: streaming, field evaluation, teach-in, perpendicular distance, native ROS 2, and more, with part numbers and firmware availability.

Source: https://sickag.github.io/sick_lidar_developer_guide/picoScan100/licenses/

# Licenses

The picoScan software packages below enable optional device functions. Activate a purchased license through the sensor's license-management workflow. The picoScan150 PRO variants (part numbers 1134610, used in the [Starter Kit](https://sickag.github.io/sick_lidar_developer_guide/picoScan100/starter-kit/), and 1142273) are delivered with the native ROS 2 license (PICOSCAN ROSCONNECT) pre-installed; check the other licenses of your variant with its Product ID on sick.com.

2D Object Detection provides configurable fields, including island fields, and Ethernet control of field configurations. The Advanced functions require the 2D Object Detection package and add teach-in, reference-contour monitoring, and perpendicular distance measurement.

## Dynamic Sensing Profiles
