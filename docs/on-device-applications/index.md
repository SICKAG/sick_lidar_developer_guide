# On-Device Applications

Use sensor-side processing to obtain application results without processing
every scan point on a host. Check each page for supported devices and limits.

* [Field Evaluation](https://sickag.github.io/sick_lidar_developer_guide/on-device-applications/field-evaluation/): configure evaluation fields and read their results.
* [Object Evaluation](https://sickag.github.io/sick_lidar_developer_guide/on-device-applications/object-evaluation/): use multiScan100 object properties to make decisions based on object criteria.
* [Perpendicular Distance Measurement](https://sickag.github.io/sick_lidar_developer_guide/on-device-applications/perpendicular-distance-measurement/): measure distance relative to a reference plane.
* [Contamination Indication](https://sickag.github.io/sick_lidar_developer_guide/on-device-applications/contamination-indication/): monitor dirt on the optics cover.
* [3D Scan Recording](https://sickag.github.io/sick_lidar_developer_guide/on-device-applications/3d-scan-recording/): record a 3D point cloud with a rotating 2D sensor.
