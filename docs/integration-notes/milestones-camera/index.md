# Set Up a SICK Camera Plugin in Milestone XProtect

> Install a SICK camera integration package, add the camera in Milestone XProtect, and align camera and LiDAR timing.

Source: https://sickag.github.io/sick_lidar_developer_guide/integration-notes/milestones-camera/

# Milestone XProtect Camera Plugin

Compatible with: LRS4000 multiScan100 picoScan100

Use Milestone XProtect to display camera video beside LiDAR events. Obtain the
camera-specific SICK/Milestone package from the applicable download page:
[LRS4000](https://sickag.github.io/sick_lidar_developer_guide/LRS4000/#downloads),
[multiScan100](https://sickag.github.io/sick_lidar_developer_guide/multiScan100/#downloads), or
[picoScan100](https://sickag.github.io/sick_lidar_developer_guide/picoScan100/#downloads). Look under software or integration
downloads. If no package is listed, contact SICK support. Confirm that the
package supports your XProtect release.

[Milestone MIP SDK documentation](https://doc.developer.milestonesys.com/mipsdk/)
explains the underlying plug-in deployment model.
