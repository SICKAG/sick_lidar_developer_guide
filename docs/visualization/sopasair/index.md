# SOPASair: The Built-In LiDAR Web Interface

> SOPASair is the built-in web interface for SICK LRS4000, multiScan100, multiScan200, and picoScan100 sensors.

Source: https://sickag.github.io/sick_lidar_developer_guide/visualization/sopasair/

# SOPASair

Compatible with: LRS4000 multiScan100 multiScan200 picoScan100

SOPASair is the sensor's built-in web UI, served directly from the device at `http://192.168.0.1/` with factory settings. There is nothing to install: point a browser at the sensor. Use it to:

- configure the settings available on the selected device,
- draw or teach in field-evaluation zones where the device supports those functions,
- update firmware through the web UI where supported, or use the documented [REST sequence](https://sickag.github.io/sick_lidar_developer_guide/shared-features/firmware-update/),
- create a diagnostic file if the device provides that option.

Screen-by-screen walkthroughs are available for the [LRS4000](https://sickag.github.io/sick_lidar_developer_guide/LRS4000/graphical-user-interface/), [multiScan100](https://sickag.github.io/sick_lidar_developer_guide/multiScan100/graphical-user-interface/), and [picoScan100](https://sickag.github.io/sick_lidar_developer_guide/picoScan100/graphical-user-interface/). Available menus and functions vary by product family, variant, and firmware. For standard IP address settings, see [Getting Started](https://sickag.github.io/sick_lidar_developer_guide/getting-started/).

For measurement recordings, see the [SOPASair Data recorder](https://sickag.github.io/sick_lidar_developer_guide/recording/sopasair/) if that function is available on your device.
