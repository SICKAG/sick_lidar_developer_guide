# GET /EtherIPMaskDHCP

> picoScan120 API | REST | OpenAPI › Ethernet

Source: https://sickag.github.io/sick_lidar_developer_guide/picoScan100/picoScan120/api-rest-openapi/#picoscan120-rest-get-etheripmaskdhcp

Returns the assigned DHCP subnet mask.

**Try the request**

Copy this command into a terminal. In Windows PowerShell, use `curl.exe` instead of `curl`.

```bash
curl --request GET "http://192.168.0.1/api/EtherIPMaskDHCP"
```
