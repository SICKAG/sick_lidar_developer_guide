# LiDAR Simulation Overview

> Explore SICK LiDAR web interfaces in the Virtual Sensor Lab or simulate sensor measurements in NVIDIA Isaac Sim before hardware is available.

Source: https://sickag.github.io/sick_lidar_developer_guide/simulation/

# Simulation

Choose a virtual web interface to explore device configuration, or a robotics
simulator to test sensor models in a scene.

* [Virtual Sensor Lab](https://sickag.github.io/sick_lidar_developer_guide/simulation/virtual-sensor-lab/): run virtual sensor web interfaces in your browser.
* [NVIDIA Isaac Sim](https://sickag.github.io/sick_lidar_developer_guide/simulation/nvidia-isaac-sim/): use SICK LiDAR models in simulated environments.
