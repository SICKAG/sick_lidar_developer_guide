# Programming Tools and Examples

Ready-made code for integrating SICK LiDAR sensors, published on GitHub (`SICKAG`). Use it as a starting point for receiving measurement data and controlling the sensor from your application. Check that a project supports your sensor firmware version (shown on the SOPASair Home page) before you start.

<p class="table-caption" markdown>**Programming Tools and Examples:** language, project, use it for, technologies used, and compatible with.</p>

| Language | Project | Use it for | Technologies used | Compatible with |
| --- | --- | --- | --- | --- |
| C++ | [sick_perception_sdk](https://github.com/SICKAG/sick_perception_sdk) | C++17 SDK: connect, configure, run diagnostics, and receive the Compact stream; includes [worked examples](https://github.com/SICKAG/sick_perception_sdk/blob/main/examples/shared_learning_examples.md). A strong starting point for custom applications. | [REST with challenge-response authentication](../configuration/rest-interface.md#challenge-response-authentication), [HTTPS](../configuration/https-and-certificates.md), [Compact](../data-streaming/compact-format.md) scan, [IMU](../data-streaming/compact-format.md#type-2-imu), and encoder telegrams ([Type 4](../data-streaming/compact-format.md#type-4-encoder)), UDP unicast and multicast, TCP, [PCD export](../recording/sick-perception-sdk.md#receive-and-record-data) | LRS4000, multiScan100, multiScan200, picoScan100 |
| C++ | [sick_scan_xd](https://github.com/SICKAG/sick_scan_xd) | Generic C/C++ API of the sick_scan_xd driver: receive point clouds without ROS on Linux and Windows. | [CoLa](../configuration/cola-interface.md) over TCP for setup, [Compact](../data-streaming/compact-format.md) or [MSGPACK](../data-streaming/msgpack-format.md) over UDP (multiScan100, picoScan100), [LMDscandata](../data-streaming/lmdscandata-format.md) over CoLa B (LRS4000), IMU | LRS4000, multiScan100, picoScan100 |
| Python | [sick_scan_rest_client](https://github.com/SICKAG/sick_scan_rest_client) | Scripted REST configuration with challenge-response handled for you. | [REST](../configuration/rest-interface.md), [challenge-response authentication](../configuration/rest-interface.md#challenge-response-authentication) (SHA-256 with salt), REST password change (AES-128, HMAC), CoLa A/B password hash | multiScan200, picoScan100 |
| Python | [sick_scan_xd](https://github.com/SICKAG/sick_scan_xd) | Python API of the sick_scan_xd driver: receive point clouds without ROS on Linux and Windows. | [CoLa](../configuration/cola-interface.md) over TCP for setup, [Compact](../data-streaming/compact-format.md) or [MSGPACK](../data-streaming/msgpack-format.md) over UDP (multiScan100, picoScan100), [LMDscandata](../data-streaming/lmdscandata-format.md) over CoLa B (LRS4000), IMU | LRS4000, multiScan100, picoScan100 |
| Python | [ScanSegmentAPI](https://github.com/SICKAG/ScanSegmentAPI) | Receive and analyze segmented scan data, for example plot it with matplotlib or record it to JSON. | [Compact](../data-streaming/compact-format.md) (telegram type 1), [MSGPACK](../data-streaming/msgpack-format.md), UDP, TCP, [JSON export](../recording/scansegmentapi-json.md) | LRS4000, multiScan100, picoScan100 |
| Python | [ScanSegmentDecoding](https://github.com/SICKAG/ScanSegmentDecoding) | Receive and decode MSGPACK scan segments without the full API. | [MSGPACK](../data-streaming/msgpack-format.md), UDP | multiScan100, picoScan100 |
| C# | [ScanSegmentAPICSharp](https://github.com/SICKAG/ScanSegmentAPICSharp) | Compact-format deserializer for .NET, with a worked example for receiving segmented scan data. | [Compact](../data-streaming/compact-format.md), UDP, .NET | multiScan100, picoScan100 |

For MATLAB, see [MATLAB Integration](matlab-integration.md). To parse the Compact format in any other language, use the [Kaitai Struct definitions](../data-streaming/compact-format.md).

For the REST API, start with the shared [REST Interface](../configuration/rest-interface.md) guide. The complete, device-specific endpoint definitions are available in the [LRS4000](../LRS4000/rest-api-openapi.md), [multiScan100](../multiScan100/rest-api-openapi.md), [multiScan200](../multiScan200/rest-api-openapi.md), and [picoScan100](../picoScan100/rest-api-openapi.md) OpenAPI references.
