# Beginner Projects

These examples outline how to turn a LiDAR use case into an application. Each
starts with a goal, a sensor-to-application data path, and practical steps for
prototyping and validation. Level 1 projects introduce guided sensor
applications, Level 2 adds 3D evaluation or point-cloud tools, and Level 3
introduces a robotics software stack.

<p class="table-caption" markdown>**Beginner Projects:** level, example, and goal.</p>

| Level | Example | Goal |
| --- | --- | --- |
| 1 | [Building security](./building-security.md) | Monitor an area (e.g. a room floor) very precisely. |
| 1 | [Bulk scan](./bulk-scan.md) | Measure woodchip profiles and calculate volume throughput using belt speed. |
| 2 | [Reversing Assistant](./reversing-assistant.md) | Detect the closest obstacle behind a vehicle and flash the warning LEDs faster as it gets closer. |
| 2 | [3D Height Measurement](./height-measurement.md) | Measure body height with a multiScan100 using perpendicular distance above a floor reference. |
| 2 | [House in 3D](./house-3d-capture.md) | Record picoScan 3D point clouds around a house and inspect the exported PCD files. |
| 3 | [ROS 2 SLAM](./slam.md) | Build a map and localize a vehicle within it using ROS 2 and SLAM Toolbox. |
