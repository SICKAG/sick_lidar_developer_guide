# GET /OpHours

> picoScan120 API | REST | OpenAPI › Operating Data

Source: https://sickag.github.io/sick_lidar_developer_guide/picoScan100/picoScan120/api-rest-openapi/#picoscan120-rest-get-ophours

Returns the total number of operating hours during the lifetime of the device. The resolution is 1/10 hour.

**Try the request**

Copy this command into a terminal. In Windows PowerShell, use `curl.exe` instead of `curl`.

```bash
curl --request GET "http://192.168.0.1/api/OpHours"
```
