# Shared Features

Find cross-device setup and maintenance workflows here. Supported parameters
and procedures vary by family; check the compatibility labels on each page.

* [Asset Administration Shell](https://sickag.github.io/sick_lidar_developer_guide/shared-features/asset-administration-shell/): access structured product data.
* [Checksums](https://sickag.github.io/sick_lidar_developer_guide/shared-features/checksums/): compare firmware, calibration, and persisted-parameter digests.
* [Device State](https://sickag.github.io/sick_lidar_developer_guide/shared-features/device-state/): inspect availability through LEDs, outputs, or device interfaces.
* [Device Discovery](https://sickag.github.io/sick_lidar_developer_guide/shared-features/device-discovery/): find sensors on the local network.
* [Error Codes](https://sickag.github.io/sick_lidar_developer_guide/shared-features/error-codes/): interpret reported errors and recommended actions.
* [Firmware Update](https://sickag.github.io/sick_lidar_developer_guide/shared-features/firmware-update/): install matching firmware through supported tools or APIs.
* [IP Address Assignment](https://sickag.github.io/sick_lidar_developer_guide/shared-features/ip-address-assignment/): change network addresses and review IP change policies.
* [LiDAR License Activation](https://sickag.github.io/sick_lidar_developer_guide/shared-features/license-activation/): activate, inspect, or deactivate feature licenses.
* [Time Synchronization](https://sickag.github.io/sick_lidar_developer_guide/shared-features/time-synchronization/): align sensor clocks using NTP or PTP.
* [UDP Unicast / Multicast](https://sickag.github.io/sick_lidar_developer_guide/shared-features/udp-unicast-multicast/): choose and configure a measurement-data transport.
* [User Levels](https://sickag.github.io/sick_lidar_developer_guide/shared-features/user-levels/): manage authentication, access levels, and password recovery.
